 # 📰 Fake News Generator

A fun, beginner-friendly Python project that generates random and humorous fake news headlines by combining different subjects, actions, and places.

## 🚀 Features

- Randomly selects a subject, action, and place.
- Generates unique and funny headlines.
- Interactive headline generation.
- Allows users to generate multiple headlines.
- Simple Yes/No input system.

## 🛠️ Technologies Used

- **Python**
- **Random Module**

## ▶️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Fake-News-Generator.git
```

**2. Navigate to the project directory**

```bash
cd Fake-News-Generator
```

**3. Run the program**

```bash
python main.py
```
